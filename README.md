## 📌 About This Project

This repository contains my **Python Fundamentals Assignment 2**, focused on understanding and practicing Python's built-in data structures and conditional statements through hands-on coding exercises.

## 📚 Concepts Covered

- **Lists** — Creating, accessing, modifying, sorting, and performing operations on lists.
- **Dictionaries** — Storing, accessing, adding, and updating key-value pairs.
- **Sets** — Understanding unique elements, set operations, union, and intersection.
- **Conditional Statements** — Applying `if`, `elif`, and `else` to make decisions in Python.
- **Exception Handling** — Understanding and handling errors using `try` and `except`.
